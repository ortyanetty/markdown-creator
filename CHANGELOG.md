## 1.0.0

- Added a Markdown File entry to the standard New File… menu.
- Added Markdown file creation from the Command Palette, Explorer context menu, and Explorer toolbar.
- Added automatic `.md` extensions, filename validation, and protection against overwriting existing files.
- Included blank file, note, README, and meeting notes templates.
- Added support for single-folder and multi-root workspaces, and file creation without an open project.
